# 열린 카페 키오스크 — 직접 해보는 테스트 시나리오

태블릿(키오스크 `/kiosk`)과 폰(스태프 `/staff`)을 나란히 두고 순서대로 진행한다. 가격은 기본 메뉴 기준(아메리카노 1,000 · 라떼 2,000 · 바닐라라떼 2,500 · 아포카토 3,000 · 샷 추가 +500)이니 메뉴를 바꿨으면 그에 맞춰 읽는다.

**시작 전**
- 폰 스태프 화면 > 매출 > `백업 내려받기` 로 DB 를 받아둔다.
- 손님 이름은 전부 `테스트…` 로 넣고, 쿠폰 전화번호는 `010-0000-00xx` 처럼 실제 없는 번호를 쓴다.
- 테스트 주문은 마지막에 **전부 취소**한다 (취소한 주문은 매출에서 빠진다).

## 1. 현금 · 매장 (가장 기본)
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 태블릿 | 커피 탭 → 아메리카노 ICE `+` 두 번 → 라떼 ICE `+` 한 번 → 주문하기 | 장바구니 합계 **4,000원** |
| 태블릿 | 매장 → 현금 → 낸 돈 `5,000원` → 이름 직접 입력 `테스트1` → 확정 | "거스름돈 1,000원" 안내, 완료 화면에 주문 번호 |
| 폰 | 만들 것 탭 (새로고침 없이) | 카드가 바로 뜬다. `테스트1 · 현금 4,000원`, 💵 `현금 5,000원 받음 → 거스름돈 1,000원` |
| 폰 | `완료` | 완료 탭으로 이동. 문자 앱이 열리지 않는다 (쿠폰 아님) |
| 폰 | 완료 탭 → `되돌리기` | 다시 만들 것 탭에 나타난다 |

## 2. 계좌이체 · 배달
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 태블릿 | 아포카토 1잔 → 주문하기 → 배달 | **1층만** 보인다 (식당, 전도사님실) |
| 태블릿 | 식당 → 계좌이체 | 계좌번호가 설정한 그대로 보인다 → `보냈어요` |
| 태블릿 | 12초 동안 아무것도 안 누르기 | 자동으로 이름 화면으로 넘어간다 |
| 태블릿 | 이름 `테스트2` | 완료 |
| 폰 | 카드 | `배달 · 1층 식당`, `이체 3,000원` |

## 3. 옵션은 한 잔씩
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 태블릿 | 아메리카노 ICE 2잔 → 주문하기 → 장바구니 | 아메리카노 줄에 `샷 추가` `연하게` `사역자` 칩 |
| 태블릿 | `샷 추가` 한 번 | 1잔만 샷 추가 (합계 2,500). `연하게` 는 그 잔에서 잠김 |
| 태블릿 | `샷 추가` 한 번 더 | 2잔 다 샷 추가 (합계 3,000) |
| 태블릿 | 논커피 탭 → 초코라떼 담기 → 장바구니 | 초코라떼 줄에는 샷/연하게 칩이 **없다** |
| 태블릿 | 현금 → 딱 맞게 → `테스트3` | 완료 |
| 폰 | 카드 | `아메리카노 ICE ×2 (샷 추가)`, `초코라떼`, 현금 5,000원 |

## 4. 사역자 무료
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 태블릿 | 바닐라라떼 3잔 → 장바구니 → `사역자` 두 번 | 합계 **2,500원** (3잔 중 2잔 무료) |
| 태블릿 | 현금 → 딱 맞게 → `테스트4` | 완료 |
| 폰 | 카드 | `사역자 2잔` 배지, 현금 2,500원 |
| 태블릿 | 아메리카노 1잔 → `사역자` | 합계 0원 → 결제 화면 없이 바로 이름 → `테스트5` → 완료 |
| 폰 | 카드 | 결제 없음, 사역자 1잔 |

## 5. 쿠폰 등록과 충전 (폰)
| 하는 것 | 기대 |
|---|---|
| 쿠폰 탭 → 이름 `테스트쿠폰` → 조회 | "쿠폰이 없습니다. 새로 등록할까요?" — 전화번호 없으면 등록 버튼 **잠김** |
| 전화번호를 넣은 뒤 이름 칸을 고치기 | 전화번호 칸이 비워진다 |
| 전화번호 칸에 `01000000011` 입력 (하이픈 없이) | 자동으로 `010-0000-0011` 모양이 된다. `0100000` 처럼 짧으면 등록 버튼이 잠긴 채로 |
| `20,000원 등록` | 잔액 20,000 · **무료 1잔** · 이력에 충전 1줄 |
| `30,000원 충전` | 잔액 50,000 · 무료 **3잔** |
| 다른 금액 `5000` → 충전 | "무료잔 적립 없음" 안내 후 잔액 55,000 · 무료 3잔 그대로 |
| 다른 금액 `30001` | 버튼 잠김, "30,000원까지" |
| `이름 변경` → `테스트쿠폰A` → 저장 | 카드 이름이 바뀐다 |
| `번호 변경` → 다른 번호 → 저장 | 바뀐 번호 표시. 저장 전엔 칸이 잠겨 있다 |
| `잔액 정정` → 잔액 `3000` / 무료 `1` → 정정 | 3,000원 · 1잔, 이력에 정정 |

## 6. 쿠폰 결제 — 무료 1잔 + 잔액 부족 → 현금
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 태블릿 | 아포카토 1잔 + 라떼 1잔 (5,000) → 매장 → 쿠폰 → 이름 `테스트쿠폰A` | 뒤 4자리 안 묻고 바로 잔액 3,000 · 무료 1잔 |
| 태블릿 | `무료 1잔 쓰기` 체크 | 무료 = **아포카토 3,000** (가장 비싼 잔), 쿠폰 2,000, 남은 잔액 1,000, 나머지 0 |
| 태블릿 | 체크 해제 | 쿠폰 3,000 + **나머지 2,000** → 현금 선택 → 낸 돈 5,000 |
| 태블릿 | 확정 | 이름 화면 **없이** 바로 완료 (쿠폰 주인 이름) |
| 폰 | 카드 | `쿠폰 3,000 + 현금 2,000`, 메모에 거스름돈 3,000 |
| 폰 | `완료` | **문자 앱이 열리고** 본문에 사용 내역 + 남은 잔액 0원 · 무료 1잔 |
| 폰 | 쿠폰 탭에서 다시 조회 | 잔액 0, 무료 1잔, 이력에 사용 (주문 번호) |

## 7. 동명이인
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 폰 | `테스트쿠폰A` 를 번호 `010-0000-0022` 로 하나 더 20,000원 등록 | 등록됨 (뒤 4자리가 다르니 허용) |
| 폰 | 같은 이름을 `010-0000-0022` 로 또 등록 | **거부** ("같은 뒤 4자리") |
| 태블릿 | 쿠폰 → `테스트쿠폰A` | 번호 목록 두 개(`010-****-0011`, `010-****-0022`)가 뜬다 → 0022 를 누르면 잔액 20,000. 숫자를 치는 키패드는 없다 |
| 폰 | 쿠폰 탭 → 이름만 조회 | 후보 2개 목록 → 골라서 열기. 전화번호 뒤 4자리를 같이 넣으면 바로 열림 |

## 8. 스태프 수정 → 차액 정산 (가장 중요)
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 태블릿 | 아포카토 1잔 현금 딱 맞게 `테스트8` | 3,000원 주문 |
| 폰 | 카드 `수정` → 아포카토 빼고 바닐라라떼(2,500) 넣기 → 저장 | 카드에 빨간 **수정됨** + 시각(현재 시간과 맞는지), 수정 내용, **돌려줄 돈 500원**. 💵 줄이 `거스름돈 500원`으로 바뀜 (딱 맞게 냈으므로) |
| 폰 | `완료` 눌러보기 | 잠겨 있고 "정산 먼저" |
| 폰 | `현금으로 줬어요` | 돌려줄 돈 사라짐 → `완료` 가능 |
| 태블릿 | 아메리카노 1잔 현금 `테스트8b` | 1,000원 |
| 폰 | 수정 → 라떼(2,000)로 바꿈 | 딱 맞게 냈으니 거스름돈이 없어 **1,000원 더 받기 — 어떻게 받았나요?** `현금으로 받았어요` / `계좌이체로 받았어요` / `쿠폰에서 빼기` → 계좌이체 선택 → 카드에 `현금 1,000원 + 이체 1,000원` → 완료 |
| 태블릿 | 아메리카노 1잔 현금, 낸 돈 `5,000원` → `테스트8c` | 💵 `현금 5,000원 받음 → 거스름돈 4,000원` |
| 폰 | 수정 → 아포카토 추가 (4,000) | 💵 `거스름돈 1,000원` 으로 줄고 **더 받을 돈 없음**, 바로 완료 가능 |
| 폰 | 💵 줄의 `잔돈 쿠폰에 넣기` | 주문자 이름 쿠폰에 1,000원 충전, 💵 `현금 4,000원 딱 맞게` |
| 태블릿 | 아포카토 현금 `테스트쿠폰A` (쿠폰 있는 이름으로) | 3,000원 |
| 폰 | 수정 → 아메리카노로 → 돌려줄 2,000 → `쿠폰에 넣기` | 후보 쿠폰(동명이인이면 고르기) → 선택 → 쿠폰 잔액 +2,000 확인 |

## 9. 쿠폰 주문 수정
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 태블릿 | 아메리카노 2잔 샷 추가 2잔 → 쿠폰 `테스트쿠폰A`(0022) 결제 | 잔액 20,000 → 17,000 |
| 폰 | 수정 모달에서 `샷 추가` 한 번 해제 → 저장 | **1잔만** 해제 (2,500). 쿠폰 잔액 17,500 — 줄어든 차액은 쿠폰으로 자동 복귀, 정산 버튼 없음 |
| 폰 | 다시 수정 → 아포카토 1잔 추가 (5,500) → 저장 | 쿠폰 잔액은 **그대로 17,500** (자동으로 더 빼지 않음), 카드에 `3,000원 더 받기` → `쿠폰에서 빼기` → 잔액 14,500, 정산 사라짐 |

## 10. 취소
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 폰 | 9번 주문 `취소` | 카드 안에 패널: 취소 확정 / 취소 안 함 → `취소 안 함` 이면 그대로 |
| 폰 | 다시 취소 → 확정 | 사라지고 쿠폰 잔액 **20,000 복구**, 이력에 환불 |
| 폰 | 1번 현금 주문 취소 | `현금으로 돌려주고 취소` / `쿠폰에 넣고 취소` 두 버튼. 쿠폰에 넣기 → 이름 같은 쿠폰 고르기 → 잔액 증가 |

## 11. 설정이 키오스크에 바로 반영
| 곳 | 하는 것 | 기대 |
|---|---|---|
| 폰 | 설정 > 카테고리 → `디저트` 추가 → 순서를 맨 위로 | 태블릿 처음 화면에 **디저트 탭이 바로 뜨고** 안은 "지금은 준비된 메뉴가 없어요" |
| 폰 | 설정 > 메뉴 → `치즈케이크` 4,500 카테고리 디저트 | |
| 태블릿 | 처음으로 | **디저트 탭이 맨 앞**, 치즈케이크 보임 |
| 폰 | 치즈케이크 스위치를 `품절` 로 | 태블릿에서 사라짐 (탭은 남음) |
| 폰 | 옵션 → `휘핑` +300 카테고리 논커피 | 태블릿 초코라떼 줄에 휘핑 칩, 아메리카노엔 없음 |
| 폰 | 장소 → `전도사님실` 숨김 | 태블릿 배달에서 안 보임 |
| 폰 | 위에서 만든 것 전부 삭제/복구 | 카테고리는 메뉴가 남아 있으면 삭제 **거부** → 메뉴 먼저 삭제 |

## 12. 입력 검증 (폰)
| 하는 것 | 기대 |
|---|---|
| 쿠폰 전화번호 `02-123-4567` | "휴대폰 번호 형식이 아니에요", 등록 잠김 |
| 전화번호 `010-123-4567` (12자) | "13자리를 다 넣어 주세요 · 지금 10/11" — 등록 잠김 |
| 전화번호 14자 이상 타이핑 | 13자에서 더 안 들어감 |
| 메뉴 가격 `1050` | "100원 단위" 안내, 저장 잠김 |
| 같은 이름 메뉴 `아메리카노` 추가 | 거부 |
| 배달 장소 층 `100` | 추가 잠김 |
| 수정 모달 이름 21자 | 20자에서 잘림 |

## 13. 매출과 백업
| 하는 것 | 기대 |
|---|---|
| 매출 탭 | 오늘 줄: 주문 수 · 현금/이체/쿠폰/무료/사역자 나뉨. 취소한 주문은 빠져 있음 |
| 펼치기 | 그날 주문 목록 |
| `CSV 내려받기` | 파일이 열리고 합계가 화면과 같다 |
| `백업 내려받기` | `.zip` 이 폰에 저장되고 파일 앱에서 열린다. 안에 `쿠폰 잔액.csv` · `매출-일별.csv` · `주문-전체.csv` · `kiosk.db`(복구용) |
| 태블릿 파일 앱 → Download/kiosk-backups | 서버 시작 시 만든 백업 파일이 있다 |

## 14. 실시간 / 로그인 / 재부팅
| 하는 것 | 기대 |
|---|---|
| 태블릿에서 주문 → 폰 (손대지 않고) | 3초 안에 카드가 나타나고 상단 집계가 바뀐다 |
| 폰 `나가기` → 다시 PIN | 틀린 PIN 은 오류, 맞으면 목록. 브라우저 닫았다 열어도 로그인 유지 |
| 태블릿 재부팅 → 1~2분 뒤 `localhost:8080/kiosk` | 서버가 혼자 올라와 있다 |
| 태블릿 2분 방치 | 키오스크가 처음 화면으로 돌아간다 |

## 끝나고 정리
1. 폰 > 만들 것 탭에서 `테스트…` 주문 전부 **취소** (완료한 건 완료 탭에서 `되돌리기` 후 취소). 취소하면 매출에서 빠진다.
2. 쿠폰 `테스트쿠폰A` 두 개: 쓰인 쿠폰은 삭제가 안 되니 `잔액 정정` 으로 0원 / 0잔.
3. 설정에서 만든 디저트/치즈케이크/휘핑 삭제, 전도사님실 다시 보이게.
4. 뭔가 꼬였으면 시작 전 받아둔 백업 파일로 되돌린다.
